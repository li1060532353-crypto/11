## 已修复的行为

- 自动保存按顺序确认服务器快照，保存中继续输入或撤销时仍会保存最新内容；手动保存等待队列完成。保存失败保留修改，不自动重复提交失败快照。
- 首次创建保留请求期间的编辑；保存并离开和首次发布会先补存最新内容。首次发布部分失败后保留文章身份，重试不会重复创建。
- 发布、撤回、版本备份与草稿保存串行执行。普通草稿 PATCH 不修改发布状态；发布携带服务器更新时间。
- 创建后的路由交接信息只消费一次，刷新或返回会重新读取服务器，避免旧草稿覆盖最新内容。加载失败只提供重试，不启用空白编辑器写入。
- 链接跳转、程序跳转和浏览器返回均受未保存保护；保存中禁止直接放弃离开，刷新和关闭使用原生提示。
- 预览直接渲染当前未保存草稿，返回编辑保留内容。
- PNG/JPEG/WebP/GIF 作为真实图片节点保存，私有 URL 在编辑器、预览、正文及表格内一致渲染。PDF 保持附件链接和下载。
- 重新打开文章加载附件；迟到的列表响应保留上传状态。当前正文、已保存草稿、发布快照或历史版本引用的附件受到删除保护。
- 后端接受真实 Tiptap 链接的空默认属性；校验图片属于当前文章且为允许的光栅格式。UUID 附件引用查询避免 D1 GLOB 模式长度限制。
- 保存确认服务器规范化后的 slug 等字段，保留请求期间新增的其他编辑。

## 页面验收步骤

1. 新建文章，输入标题并保存；请求期间继续输入，确认跳转后新内容仍在，刷新后内容一致。
2. 修改已有文章，保存中撤销回原内容，确认最终服务器也回到原内容。
3. 上传图片，插入正文及表格，保存、刷新、预览和阅读，确认图片显示；尝试删除被引用图片，应提示受保护。
4. 修改已发布文章后撤回，确认编辑内容保留；模拟发布失败后重试，不应新增第二篇文章。
5. 修改后点击其他页面或浏览器返回，分别选择继续编辑、保存并离开、放弃修改并离开，确认对应结果。
6. 未保存时打开草稿预览，再返回编辑，确认内容和保存状态保留。
