# 站内登录与云端完整体验方案

日期：2026-10-02
状态：待用户审阅；替代原主规范中的 Cloudflare Access 认证要求。

## 已确认目标

已发布文章公开浏览。整个知识库及所有写入操作要求管理员登录。保留已经迁移到生产的 8 篇笔记、5 个历史版本、原 ID 和状态。继续使用现有 Cloudflare Pages、D1、私有 R2，不依赖 Access，不开放注册或多用户功能。

## 用户体验

增加 `/login` 中文登录页，沿用当前页面样式。未登录访问 `/knowledge` 及其子路由时跳转登录；成功后返回原站内地址。提供明确的登录错误、提交状态和退出入口。登录状态失效后重新登录，不丢弃正在编辑的内容，也不重复提交写入请求。

首次部署创建一个管理员账号（默认用户名 `admin`）；初始密码随机生成，通过本机文件交付，不在聊天、Git、构建产物和日志中显示。后续通过本地配置工具设置新密码；不增加公开注册、密码找回或公开初始化接口。

## 服务端认证

使用 Web Crypto PBKDF2-SHA256 加随机盐生成密码校验值，参数保存在 Cloudflare 加密环境变量中。明文密码不进入数据库或代码。采用 D1 存储的随机不透明会话，数据库只存会话令牌的 SHA-256 摘要；生产 Cookie 使用 Secure、HttpOnly、SameSite=Lax 和固定路径，默认 12 小时过期。退出撤销当前会话；更新密码撤销旧会话。

新增登录、状态查询与退出接口。所有认证及私有响应使用 Cache-Control: no-store。登录请求限制大小；错误提示不区分用户名/密码错误。数据库保存短期失败计数与锁定时间，限制重复尝试；不把明文密码、令牌或 Cookie 写入日志。

登录、退出以及所有写入请求严格验证 Origin 为当前站点，拒绝跨站请求。生产缺失认证配置时拒绝访问；现有本地开发 bypass 仅在 localhost/127.0.0.1 且显式启用时生效。不能通过客户端路由守卫替代 API 认证。

## 公开内容边界

提供独立的只读已发布内容 API，强制 status=published，并且只读取发布快照；不能通过查询参数读取草稿、归档、历史版本、私有附件或正在编辑的未发布正文。公开输出明确列出允许字段。知识库原 `/api/notes`、`/api/stats`、`/api/search`、导入、附件和全部写入接口仍需登录。

前台文章列表、详情和搜索整合静态文章及已发布数据库文章。静态文章源文件保留。云端不再尝试调用未部署的 NestJS `/api/v1` 内容 API，以避免长期错误回退；保留旧 API 的独立开发能力。未发布变更不自动反映到公开页面。

## 变更范围

新增可复现的会话/登录限流数据库迁移；认证模块与接口；替换 Functions 中间件的 Access 校验；增加公开发布快照接口；登录页、知识库登录守卫和退出入口；更新前台云端内容访问适配及认证文档。尽量复用现有 Notes 服务、发布快照和 UI，不改文章格式或自动保存语义。

## 验证与部署

先测试匿名不能访问知识库或任何写入接口；错误密码、限流、过期、伪造/撤销会话、跨站写入均被拒绝。测试公开查询不能泄露草稿或未发布修改；登录后笔记读取、修改、保存、刷新持续存在，退出后私有请求被拒绝。

运行相关单元/集成测试、Functions 和前端类型检查、lint 与生产构建。再次备份生产 D1 后应用新增迁移与认证变量，部署现有 Pages 生产项目。用匿名浏览器与管理员浏览器分别验证文章、登录、知识库、新建、编辑、退出和刷新持久化。
